Desko

An interactive desk robot built around an ESP32-S3, combining sensors, display, audio input/output and custom embedded software.

01 — OVERVIEW

What it is

Desko is a hands-on embedded systems project focused on building a responsive desktop robot rather than a purely software prototype. The system combines a microcontroller, display, microphone, speaker amplifier and sensors into one compact platform.

02 — SYSTEM

Technical details

Core controllerESP32-S3 with custom firmware and Wi-Fi connectivity.
User interfaceSSD1306 OLED and touch/interaction elements.
Audio inputINMP441 digital microphone using I²S.
Audio outputMAX98357A mono amplifier and speaker using I²S.
CommunicationI²C used for peripheral sensors/display.
Engineering focusHardware integration, firmware architecture, real-time I/O and debugging.
03 — ENGINEERING

What I worked on

A major part of the work has been diagnosing real embedded-system race conditions. The audio system uses concurrent I²S activity, and configuration changes require careful coordination between Wi-Fi/HTTP handling and the main processing loop. Testing also covered I²S Philips/standard format behavior, channel selection and playback/recording interactions.
